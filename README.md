# Ключевая ставка ЦБ vs российский рынок акций

Исследование влияния изменений ключевой ставки ЦБ РФ на индексы IMOEX, RTS и отдельные бумаги.

## Что внутри

- Загрузка ставки ЦБ с cbr.ru и котировок с MOEX ISS
- Лаг-корреляция, SARIMAX, VAR, тест Грейнджера
- Бэктест событийных стратегий (лонг/шорт по решениям ЦБ)
- Cross-section спрэд: экспортёры vs внутренний спрос

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

По умолчанию используются синтетические данные (`USE_SYNTHETIC = True` в `config.py`).
Для реальных данных поставить `False` — нужен доступ к cbr.ru и iss.moex.com.

## Структура

```
config.py       — параметры
fetcher.py      — загрузка данных (ЦБ, MOEX ISS)
synthetic.py    — генерация синтетических данных
backtest.py     — метрики и бэктест
main.py         — основной скрипт
```
